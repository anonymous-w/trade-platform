# v0.2 系统检查与优化（2026-10-13）

范围：`trade-platform-v0.2` 本地 Docker 系统的认证、查询、详情、CSV、PDF、界面和数据库完整性。所有写入测试都在独立的 `trade-platform-audit` 数据库副本进行；正式本地数据不混入测试账号和 AUDIT 记录。

## 已修复与改善

| 领域 | 原问题 | 本次处理 |
|---|---|---|
| 登录 | Enter 和表单提交可重复触发；网络错误只显示 CSRF initialization failed | 单一提交入口、防重复提交；更新运行说明与日文界面错误提示；CSRF 请求合并，仅对 CSRF 过滤器拒绝的请求刷新并重试一次 |
| 会话与权限 | 会话失效无明确恢复流程；USER 上传被错误处理为500 | 401返回登录，403显示权限不足；异常分类为400/403/404/409/413等，真正服务器错误写入日志 |
| 登录保护 | 数据表已有失败次数/锁定字段但未使用 | 连续5次密码失败锁定账号5分钟，成功登录清零并记录 last_login_at；不修改现有密码 |
| 搜索 | 无业务编号综合检索；日期倒置静默空结果；输入通配符扩大匹配 | 增加统一关键词 OR 检索；高级条件仍 AND；校验日期；转义 `%`、`_`、反斜线 |
| 列表 | 未提交的搜索条件会影响分页或CSV；较慢请求覆盖新结果 | 区分编辑中/已提交条件；按请求序号丢弃过时响应；CSV与列表使用相同筛选 |
| 详情 | 失败时空白或一直“加载中”；路由切换可保留旧ID | 错误状态和重试；按路由重新装载；批量读取包装明细，消除逐设备查询 |
| CSV导入 | 不支持UTF-8 BOM；同出口的客户/设备/日期不一致可能被忽略 | BOM兼容；完整表头一致性、长度、日期、数值范围/精度校验；已有主数据编码的名称/型号必须一致；任意错误整批回滚 |
| CSV导出 | 超过10000行时静默截断 | 明确拒绝并提示缩小筛选范围；确定性排序；保留公式注入防护 |
| PDF | 不存在的关联记录在写文件之后才报错 | 写文件前校验关联记录、ID、文件名长度；保留大小/签名校验和失败文件清理；记录上传人 |
| 上传界面 | 要求手填内部ID；普通用户能看到可点击上传 | 改为按业务编号/客户搜索选择；隐藏USER上传入口；前端文件大小/扩展名校验；可读的成功结果 |
| 布局 | 窄屏侧栏挤占内容；语言混用 | 自适应表单和导航、横向滚动表格、日文组件语言和提示；路由按需加载 |
| 数据库 | 文件存储键可重复，部分排序查询缺索引 | 新增V2迁移：storage_key唯一约束、包装/出口/订单/最近文档查询索引；V1原样保留 |
| 初始化 | 演示种子多次写入无整体事务 | 首次管理员及演示数据使用事务，失败不留下部分初始化 |
| 运行 | 后端容器重建后代理可能缓存旧地址 | Nginx通过Docker DNS定期重新解析后端；依赖锁文件和npm ci保证前端构建可重复 |
| 项目命名 | 文件夹名派生的Compose项目名可能指向另一套数据卷 | 本机固定COMPOSE_PROJECT_NAME=trade-platform-v02；README提供显式-p的启动/停止命令 |

数据库原有的出口—设备—装箱单复合外键、主数据与业务快照分离、装箱单原票汇总与明细分离是合理设计，本次保留。没有删除表、重编号、批量改写业务内容，也没有引入新的ORM。

## 现有业务边界

- 销售创建、审批、编辑/删除，以及用户管理界面仍未实现；销售模块是只读查询。
- 五年监视为参考记录展示，未实现提醒任务或法律义务判定。
- CSV仍是受限草稿导入：一出口/一设备/一发票/一箱型配置；地址、目的地等使用待核实占位值，金额为0。真实业务使用前需补齐确认与编辑流程。
- 没有OCR、自动装箱算法、真实业务迁移验收或多客户数据隔离设计。
- PDF校验是文件扩展名、大小和签名级别，不包括恶意内容扫描；打印按钮未接真实打印机验证。
- Vite仍有Element Plus主包较大的构建提示；页面已按需拆分，进一步按组件引入可后续处理。
- 未完成全浏览器/真实手机兼容性、负载测试、Java及镜像漏洞扫描、生产HTTPS与正式账号权限验收。

## 退出按钮显示问题的补充修复

复现：退出按钮位于侧栏最底部，长列表和详情撑高外层容器后，按钮被推到首屏之外；向下滚动时顶部账户信息也会离开视口。

修复：将退出按钮统一移到顶部账户栏；应用使用视口高度，业务内容独立滚动，菜单和顶部退出入口始终可见。手机宽度保留横向导航和顶部退出按钮，打印时恢复内容自然展开；切换路由时重置内容滚动位置。页面入口禁用长期缓存，刷新后获取更新资源。

验证范围：出口列表/详情/文件预览、集装箱、销售列表/详情/文件预览、数据导入、五年监视；长页面滚动、窄屏以及实际退出。前端构建和项目静态检查在补充修改后重新执行。
